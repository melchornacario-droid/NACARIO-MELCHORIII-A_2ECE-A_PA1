# NACARIO-MELCHORIII-A_2ECE-A_PA1
At the end of this laboratory activity, the student should be able to: 1. use basic Python functions, operators, and string operations; 2. manipulate strings using indexing, slicing, and built-in string methods; 3. apply sequence unpacking to manipulate the elements of a list; and 4. construct simple Python functions that return a specified result.
